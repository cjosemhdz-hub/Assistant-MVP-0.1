Carga de datos

Esta versión no necesita tocar código. Carga un archivo data_mfa.json con la estructura del motor MFA y el tablero se recalcula.

Formato sugerido: empresa, periodo, balance, resultados, bancos, cobranza, integridad y acciones.

También puedes usar el botón “JSON ejemplo” para descargar una plantilla base.

Estructura mínima JSON
{
  "empresa": "Cliente Demo",
  "periodo": "Mayo 2026",
  "moneda": "MXN",
  "resultados": { "ingresos": 0, "costoVentas": 0, "gastosAdmin": 0 },
  "bancos": { "saldoInicial": 0, "ingresos": 0, "egresos": 0 },
  "balance": { "activoCirculante": 0, "pasivoCirculante": 0 },
  "cobranza": { "saldoClientes": 0, "cobrado": 0, "topClientes": [] },
  "integridad": { "score": 100, "cuentasSinClasificar": 0 }
}
